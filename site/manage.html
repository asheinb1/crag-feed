1. Connect to GitHub

Checking…

Anyone can look at this page, but only someone with your GitHub token can change anything. The token is kept only in this browser and is sent only to GitHub. It is never stored in the repository or on the website.

How to create the token (one time, about 3 minutes)
  1. Open github.com/settings/personal-access-tokens/new (sign in if asked). Button labels may differ slightly.
  2. Token name: Crag Feed manage. Expiration: 90 days or longer.
  3. Under Repository access choose Only select repositories, then pick crag-feed.
  4. Under Repository permissions set Contents to Read and write and Actions to Read and write. Leave everything else alone.
  5. Click Generate token, copy it (it starts with github_pat_), and paste it above. GitHub only shows it once.
  6. When it expires, this page will say GitHub rejected the token. Just make a new one the same way.
